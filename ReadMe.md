# FixMate – Backend

FixMate Backend is a RESTful API built to power the FixMate device and home appliance repair service platform. It handles authentication, user management, service listings, bookings, technician operations, admin management, and secure online payments.

The backend uses Node.js and Express.js with MongoDB for data storage. Better Auth provides authentication and role-based access control, while Stripe handles secure payment processing.

## Technologies Used

- Node.js
- Express.js
- MongoDB
- Better Auth
- JWT (JSON Web Token)
- Stripe
- ImgBB API
- Axios (Frontend API Communication)
- dotenv
- CORS

## Key Features

- Secure user authentication and authorization
- Role-based access for Customer, Technician, and Admin
- Service creation, management, and approval
- Customer booking and technician job management
- Booking status updates and workflow management
- Stripe Checkout payment integration
- Stripe webhook for payment verification
- User profile management
- Image upload using ImgBB
- Protected REST API endpoints
- MongoDB database integration

The backend server will run at:

`http://localhost:5000`
